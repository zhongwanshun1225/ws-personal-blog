## 0. 身份模型：本站在传统网站谱系里的位置

传统内容站点（WordPress / Ghost / Medium / 掘金 / CSDN / 知乎专栏 / 传统论坛）通常划分 5~7 类身份。
本站实现了其中 5 类，另有 1 类部分实现：

| # | 传统网站身份 | 本站 | 落地形态 | 缺口密度 |
| --- | --- | --- | --- | --- |
| 1 | 游客 Visitor | ✅ 已实现 | 无需登录浏览全部公开内容 | 中 |
| 2 | 注册读者 Member | ✅ 已实现 | 评论 / 点赞 / 收藏 / 个人中心 | **高** |
| 3 | 投稿作者 Contributor·Author | ✅ 已实现 | `/write.html` 写稿 → 送审 → 发布 | 中 |
| 4 | 编辑 Editor（二审角色） | ❌ **缺失** | 无中间层，只有「管理员」一档 | — |
| 5 | 管理员 Administrator | ✅ 已实现 | `/admin.html` 六面板 | 中 |
| 6 | 付费订阅者 Subscriber | ⛔ 不适用 | 个人博客形态，建议不做 | — |
| 7 | 机器身份（爬虫 / RSS / 社交抓取） | ✅ 已实现 | RSS·sitemap·canonical·og:image（含默认图回落）·JSON-LD 完备 | 低 |
| 8 | 受限账号（禁言 / 封禁 / 注销中） | ⚠️ 部分 | 可禁用并拦截写操作，但无原因/期限/申诉 | 低 |

> **一句话结论**：`浏览 → 注册 → 互动 → 投稿 → 审核 → 发布 → 改稿 → 管理` 这条**主链已闭环**；
> 缺的是 **社区（人与人之间）**、**运营（数据与在线配置）**、**合规（隐私与注销）** 三类横向能力，
> 以及**站外通知**（站内通知中心已做，邮件/推送仍未做）。

## 1. 游客（未登录）

### 1.1 已有的能力

- 首页（Hero / 实时统计 / 文章列表 / 标签筛选 / 精选项目）、文章列表、文章详情、项目集与详情、归档（按年，**已自动分页**）、标签云与标签详情、关于、404（**带搜索 + 最新文章 + 热门标签**）
- 站内搜索：客户端索引，`Ctrl / ⌘ + K` 与 `/` 唤起，键盘上下选择，**单次最多 12 条**；关键词同步进 URL（`?q=`，可刷新可分享）
- 阅读增强：目录（桌面悬浮 + 移动端可展开卡片）、滚动高亮、阅读进度条、代码高亮与一键复制、图片点击放大、上一篇 / 下一篇、**静态文章与云文章都有**的相关推荐
- 分享：文章详情页有分享条（复制链接 / 微博 / X / 系统 share API）
- 外观：跟随系统 / 浅色 / 深色 + 5 种强调色，首屏防闪；`prefers-reduced-motion` 已适配
- PWA：`site.webmanifest` + Service Worker（离线页 `offline.html`），可「添加到主屏」
- 面包屑：文章详情、项目详情、标签详情、作者主页、归档、云文章列表与详情、通知页**已有**（首页 / 文章列表 / 标签云没有）
- 分发：`feed.xml`、`sitemap.xml`、`robots.txt`、canonical、og:type/title/description/url/image、twitter:card、JSON-LD `BlogPosting`（静态与云文章均有）
- 互动区可见：点赞数 / 收藏 / 评论 / 阅读量都展示，点下去才要求登录

## 3. 投稿作者（Contributor）

### 3.1 已有的能力

- `/write.html`：Markdown 编辑器、**实时预览**、**插图上传**（云存储 → 自动插入 `![]()`）、标签 / 摘要 / 自定义 slug、**草稿自动保存 + 本地恢复**（防抖 + 失焦/关页刷盘，30 天过期）
- 状态机：`draft`（草稿，仅自己可见）→ `pending`（提交审核，可撤回）→ `published`（通过，前台可见）
  / `rejected`（驳回，显示站长理由，改完可重投）
- **已发布文章可自行修改**（第四批）：走 RPC `author_update_post` ——
  受信任作者（管理员，或逐个开过 `can_publish` 的账号）改完**立即生效**；
  其余作者写进 `edit_*` 影子列，主字段全程不动，**线上一直是旧版本**（读者无感），
  站长在后台「待审改稿」通过后才替换，附新旧全文对照
- 权限边界在数据库：RLS 限定投稿者只能写 `draft / pending / rejected`；改稿只能走上面的 RPC

   要看「现在还剩多少」请直接看 8.1 的剩余 P0 清单。
3. **云端对象口径随时可查**：`11 表 + 2 视图 + 42 函数` 是本次实测值，新增迁移后需要重查。
   查询方式：走 `mcp__genie-baas__workbuddy_cloudservice_db_exec_sql`（`mode=read`）执行
   ```sql
   SELECT (SELECT count(*) FROM information_schema.tables
            WHERE table_schema='public' AND table_type='BASE TABLE') AS tbls,
          (SELECT count(*) FROM information_schema.views
            WHERE table_schema='public') AS views,
          (SELECT count(*) FROM pg_proc p JOIN pg_namespace n ON n.oid=p.pronamespace
            WHERE n.nspname='public') AS funcs;
   ```
   （42 = 35 个可直接调用 + 7 个触发器函数；触发器函数要按 `prorettype='trigger'::regtype` 排除）
