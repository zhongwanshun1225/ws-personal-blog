## 0. 六类身份与判定口径

| 身份 | 入口 | 判定依据（代码位置） | 数量上限 |
| --- | --- | --- | --- |
| **游客 Guest** | 无需登录 | 无会话即游客 | — |
| **注册读者 Member** | `login.html` | 登录会话 + `profiles.status='active'`（`is_active()`） | 不限 |
| **投稿作者 Contributor** | 读者 + `can_publish` | `profiles.can_publish = true`；也可按篇提交，走审核 | 不限 |
| **编辑 Editor** | 后台 | `my_admin_role()` 返回 `editor`（`profiles.is_editor`） | 不限 |
| **管理员 Administrator** | 后台 | `my_admin_role()` 返回 `admin`，源 `admin_emails` 白名单 | 白名单 |
| **机器身份 Bot/Robot** | 无 UI | HTTP 请求方：搜索引擎、RSS 阅读器、社交平台预览、爬虫 | — |

**三个判定函数**（都在云端，前端只做界面显隐，真正放行由各自的 RPC 检查）：

- `is_active(uid)` —— 读者可用性闸门
- `is_staff()` —— `admin` 或 `editor`
- `is_admin()` —— 仅管理员

> ⚠️ 口径提醒：前端 `applyRole()` 的界面隐藏只是**减速带**，不是安全边界。
> 任何"谁能做什么"的结论，看的是 RPC 函数体第一段的身份校验，不是按钮显不显示。

## 1. 游客 Guest · 不登录能得到什么

**这一节是本站的"公共产品"**，也是搜索引擎与社交平台看到的东西。

### 1.1 内容浏览

| 能力 | 落点 | 说明 |
| --- | --- | --- |
| 首页（分页） | `index.html` | 置顶优先 + 时间倒序，卡片含封面 / 摘要 / 标签 / 阅读时长 |
| 文章详情 | `posts/<slug>.html` | 目录、代码高亮、上一篇/下一篇、相关推荐、分享块 |
| 云端文章详情 | `post.html?slug=` | 云文章按需渲染（`cloud-markdown.js`），与静态文章同一套版式 |
| 云文章列表 | `posts.html` | 云端文章分页列表 |
| 项目展示 | `projects.html` + `projects/<slug>.html` | 项目卡 + 详情页 |
| 标签总览 / 单标签 | `tags.html` / `tags/<tag>.html` | 标签云 + 该标签下全部文章 |
| 系列 | `series.html` / `series/<slug>.html` | 按 front matter 的 `series` 归集，支持多篇连续阅读 |
| 归档 | `archive.html` | 按月分组 |
| 作者主页 | `authors/<owner_id>.html` | **只给有已发布文章的作者建页** |
| 关于页 | `about.html` | 正文在 `content/pages/about.md` |
| 法律页 | `privacy.html` | 正文在 `content/pages/privacy.md` |

### 1.2 站内检索与发现

| 能力 | 实现 |
| --- | --- |
| 站内搜索 | 构建期生成 `assets/search-index.json`，前端纯客户端检索（无服务端依赖） |
| 快捷键面板 | `shortcuts.html` 列出全部快捷键（`?` 唤起） |
| 分类导航 | 顶部导航 + 标签云 + 系列入口 |

### 1.3 互动（游客态）

| 能力 | 说明 |
| --- | --- |
| 阅读评论 | 已通过的评论公开可读（`comments_public` 视图 + `post_comments()`） |
| 看点赞数 / 评论数 / 浏览数 | `post_interaction(p_slug)` 匿名可读 |
| 阅读进度记录 | **本地** `localStorage`（`wsblog:resume`），下次打开提示"继续阅读" |

| 点赞 / 收藏 / 评论 / 举报 | **需要登录** —— 点击后跳 `login.html`（`goLogin()`） |

> 边界很清楚：**读全部免费，写一律要身份**。

### 1.4 订阅与分发

| 能力 | 落点 |
| --- | --- |
| RSS 订阅 | `feed.xml`，含 `<category>` 标签 |
| 邮件订阅入口 | `subscribe.html`，填邮箱即订阅（`subscribe_add()`），带退订令牌 |

### 1.5 访问追踪（对游客透明）

`page_view_log(path, referrer, ua, session)` 由 `analytics.js` 上报。
**不采 IP 明文、只存哈希；尊重 DNT；会话指纹按天轮换；可在隐私页关闭**。

## 3. 投稿作者 Contributor · 内容生产

> 前提：读者身份 + `can_publish`（或按篇提交走审核）。入口 `write.html`。

### 3.1 写作

| 能力 | 实现 |
| --- | --- |
| Markdown 编辑 | 纯手写 Markdown，`write.js` |

| 摘要字段 | 可留空，构建期自动截取 |

### 3.2 发布流程

| 能力 | 实现 |
| --- | --- |
| 存草稿 | 本地草稿 + 云端 `status='draft'` |

### 3.4 我的投稿

## 6. 机器身份 Bot / Robot

| 能力 | 落点 | 说明 |
| --- | --- | --- |
| 站点地图 | `sitemap.xml` | 文章含 `lastmod`，按 priority 分级 |
| 抓取规则 | `robots.txt` | `User-agent: *` + Sitemap 行 |
| RSS | `feed.xml` | 每条含 `<category>`；description 只放摘要 |
| 结构化数据 | 各页 `<script type="application/ld+json">` | 文章 `BlogPosting`、作者 `Person` |
| 社交预览 | `og:*` / `twitter:*` meta | 标题 / 描述 / 图片 / URL |
| 规范链接 | `<link rel="canonical">` | 指向云域名 |

## 9. 复核方法与已知边界

### 9.1 这份清单怎么来的

1. **页面层**：`grep "^def " wsblog/templates/pages.py` → 35 个渲染函数，逐一对照产出页面
2. **脚本层**：`ls src/scripts/*.js` → 25 个，按函数名归纳能力
3. **数据层**：线上库实测表 / 视图 / 函数，`grep "rpc('…')" src/scripts/` → 前端真正调用的 73 个
4. **权限层**：`is_active` / `is_staff` / `is_admin` / `my_admin_role` 四个判定，逐个 RPC 核对

### 9.2 数字口径（避免误读）

- **云端 161 函数**里含 **22 个 pgcrypto 扩展函数**（多个重载，实际占 30 个签名：`encrypt` / `digest` / `hmac` /
  `pgp_*` / `armor` 等）与 **10 个触发器函数**，业务可调用的是 **151 个**；
  前端真正发起调用的 **73 个**，其余是内部工具与 RLS 判定函数
  （`url_encode` / `display_name_for` / `b32_encode` / `is_active` / `is_staff` / `request_header` 等）。
- **页面 63 个**（`find dist -name "*.html" | wc -l`，含 `404` / `offline` / `preview` 这类工具页）。
- **后台标签页 14 个**（以 `data-admin-tab` 去重为准）；编辑可见 10 个，管理员 14 个。
  ⚠️ 早前文档写「15 个」，是数错了 —— 以代码为准。
- **本文 35 个函数引用已逐个对照线上库校验，无虚构**（`.preview/check-feature-list.py`）。
- **回归护栏 16 探针 766 断言**（本轮加 `dist-clean-test.mjs` 4 项）。

### 9.3 ⚠️ 线上有、仓库没有的 3 个函数（真实风险，非清单误差）

复核时用线上函数清单与 `cloud/sql/*.sql` 对差，发现 **3 个函数只活在线上，仓库里没有定义语句**：

| 函数 | 被谁用 | 影响 |
| --- | --- | --- |
| `post_interaction(p_slug)` | `interact.js` 读点赞 / 收藏 / 评论数 / 浏览数 | 缺了 → **文章页互动数据全空** |
| `admin_list_emails()` | 后台「管理员白名单」 | 缺了 → **白名单页打不开** |
| `is_admin()` | 大量 RPC 的身份闸门 | 缺了 → **整个后台与审核链失效** |

> 这是「线上才是事实」的反面：**仓库不等于线上**。
> 现在重建一次数据库，这三个函数就没了，而依赖它们的 40+ 个 RPC 会连带瘫痪。
> 建议下一步把它们补成迁移文件（`CREATE OR REPLACE`，从线上 `pg_get_functiondef()` 导出），
> 并入 `cloud/sql/`。**这是本次复核新发现的问题，缺口清单里此前未收录。**

### 9.4 本地验不到的部分

云端按 Origin 白名单只放行 `https://ws-blog.app.workbuddy.host`，本地 `127.0.0.1` 上
登录 / 评论 / 投稿 / 后台全部 **403**。所以「谁能做什么」的**运行时行为**只能在线上手测；
本文的结论来自**代码取证**（RPC 函数体里的身份校验），不是点了按钮看到的。

⚠️ `admin.html` / `write.html` 在本地做 DOM 快照拿到的是登录页 —— `guardAdmin()` 无会话即跳转，
**这是预期行为，不是缺陷**。
