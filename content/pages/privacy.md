本站是一个个人技术博客，内容以阅读为主；只有在你**主动注册、投稿、评论或订阅**时，才会涉及个人信息。
这份政策如实说明本站实际做了什么——不写漂亮话，也不留模糊地带。

## 一、收集哪些信息

### 1. 账号信息（你主动注册或首次登录时）

- **邮箱**：作为账号标识，用于登录、找回密码、接收审核结果与通知。
- **密码**：由云服务加密存储，本站任何代码都接触不到明文。
- **昵称、头像**：你在账号设置里填写的展示信息，会出现在你的评论与投稿署名处。
- **第三方登录**：若你选择微信 / Google / WorkBuddy 登录，本站只接收该平台返回的**身份标识与昵称**，
  不会获取你的密码或通讯录。

### 2. 内容信息（你主动投稿或评论时）

- 投稿与评论的**正文、标题、标签、时间**。
- 你提交内容时的**浏览器大类**（如 Chrome / Safari）与**IP 的哈希值**——用于反垃圾风控。
  哈希是**不可逆**的，本站不保存 IP 明文，也无法从哈希反推出你的 IP。

### 3. 访问统计（你只是来读文章时）

本站使用**自建的、刻意最小化**的访问统计：

| 记录 | 不记录 |
| --- | --- |
| 访问路径、来源域名（如 `github.com`） | **IP 地址** |
| 浏览器大类、是否被判定为爬虫 | 精确地理位置 |
| 一个「会话指纹」 | 跨站追踪标识（无第三方 Cookie） |

会话指纹的构造方式：浏览器会话内生成一个随机串，与**当天日期**拼接后做 SHA-256，只取前 16 字节。
它**当天有效、次日更换**，因此无法用来跨天串联你的阅读轨迹。

### 4. 邮件订阅（你主动订阅时）

只保存**邮箱、语言偏好、订阅来源、确认时间**，并采用双向确认（订阅后需点邮件里的确认链接）。

### 5. 保存在你浏览器本地、不上传的信息

界面语言、未提交的草稿、阅读进度、公告与统计开关等，存在浏览器的 `localStorage` / `sessionStorage` 里，
**不会上传到服务器**，清空浏览器数据即可清除。

### 6. 服务商侧的请求日志

本站由**腾讯云开发**提供托管、数据库与文件存储，因此请求会经过服务商并产生其用于安全防护与故障排查的访问日志。
若启用邮件订阅推送，邮件地址会交由对应的邮件发送服务处理。

## 二、这些信息用来做什么

1. 展示你的评论与投稿内容、回复你的评论、把审核结果通知到你；
2. 统计哪些文章被读过（**只用于了解内容效果，不做用户画像或个性化推荐**）；
3. 识别垃圾评论与恶意请求，保护站点与读者；
4. 发送你主动订阅的更新邮件。

**本站不卖数据、不做广告投放、不与第三方共享用于营销。**

## 三、保存多久

- **账号与内容**：保存至你注销为止。
- **访问统计**：按天聚合保存，用于趋势对比。
- **订阅关系**：直到你退订。退订后邮箱仍会短暂保留在退订名单里，用于避免误发。

## 四、你的权利（全部可自助操作）

| 你想做的事 | 在哪里做 |
| --- | --- |
| 查看 / 更正昵称、头像 | 账号设置 |
| **导出自己的全部数据** | 账号设置里的「导出我的数据」（JSON 文件） |
| **注销账号** | 账号设置里的「注销账号」：评论、投稿、点赞、收藏、订阅、通知等会被**真实删除**，资料页只留一条不显示个人信息的墓碑记录 |
| 退订邮件 | 邮件里的退订链接，或账号设置 |
| **关闭访问统计** | 在浏览器控制台执行 `WSBlogAnalytics.optOut()`；或者开启浏览器的 **Do Not Track**，本站会直接跳过上报 |

> [!IMPORTANT]
> 注销是**立即生效、不可撤回**的。另外需要如实告知：受云平台能力限制，
> 本站可以删除你的**全部内容与资料**，但云平台侧的**登录凭证记录**无法由本站直接抹除
> （该限制在注销确认界面里也会明确提示）。

## 五、Cookie 与本地存储

本站**不使用第三方 Cookie，也不接入第三方统计或广告脚本**。
站点自身只在你浏览器里写少量本地存储（见上文第 5 条），用于记住语言、草稿等偏好；
其中访问统计的关闭开关也保存在本地。

## 六、未成年人

本站内容面向成年技术读者，不面向 14 周岁以下的儿童。若发现存在未成年人注册，
我们会删除其账号与相关内容。

## 七、政策变更

本政策如有实质调整，会更新本页顶部的「最后更新」日期；涉及权利变化的重大调整，
会在站内公告中提示。

## 八、联系方式

对本政策有疑问、或希望行使上述权利但遇到障碍，可通过「关于」页列出的联系方式与我联系，
也可以直接在本站任意文章下留言。
