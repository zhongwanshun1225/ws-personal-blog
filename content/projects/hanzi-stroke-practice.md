## 需求很具体

家里小朋友上小学，语文作业要求"按笔顺书写"。市面上的 App 要么广告太多，要么笔顺数据不权威。

于是决定自己做：**数据用权威字库，界面干净，不要有游戏化诱导**。

## 主要功能

### 笔顺动画

Canvas 逐笔画绘制，支持调速和单步暂停：

```js
Page({
  data: { strokes: [], current: 0, speed: 800 },

  drawStroke(index) {
    const path = this.data.strokes[index];
    const ctx = this.ctx;

    ctx.setStrokeStyle('#2dd4bf');
    ctx.setLineWidth(12);
    ctx.setLineCap('round');

    // 用 t 做插值，实现"一笔画下去"的效果
    let t = 0;
    const timer = setInterval(() => {
      t += 0.06;
      if (t >= 1) { clearInterval(timer); t = 1; }
      this.drawPartial(path, t);
    }, 16);
  }
});
```

### 描红模式

半透明灰色底字，小朋友在上面照着写，写完自动判断像不像：

- 笔画的**起始位置**和**方向**比形状更重要；
- 用简化算法（关键点距离 + 方向角）而不是完整的图形匹配，误判率可以接受。

> [!TIP]
> 判断"像不像"这件事上，**宁可宽松也不要严格**。判错的挫败感对小朋友的伤害，远大于放过一个写得不太好的字。

### 错字归档

写错的字自动进错题本，按"字典序 / 错误次数 / 最近错误"三种方式排序。这是家长最需要的功能。

## 技术选择与代价

| 决策 | 选择 | 原因 |
| --- | --- | --- |
| 笔顺数据 | 静态 JSON 包 | 共 3000 常用字，压缩后 1.2MB，走分包加载 |
| 动画 | Canvas 2D | 相比 SVG，绘制路径插值更自然 |
| 后端 | 云开发 | 免登录态管理，成本几乎为零 |
| 存储 | 本地 + 云同步 | 无账号体系，用设备 ID 关联 |

## 遇到的问题

### 1. 1.2MB 的数据包

首次打开加载明显。最后的方案是按使用频率分包：前 500 常用字打进主包，其余按拼音首字母分 26 个分包，用到才下载。

### 2. Canvas 在部分安卓机上模糊

需要按 `devicePixelRatio` 放大画布再缩回来：

```js
const dpr = wx.getSystemInfoSync().pixelRatio;
canvas.width = width * dpr;
canvas.height = height * dpr;
ctx.scale(dpr, dpr);
```

### 3. 小朋友会乱点

一开始没做防抖，快速点击会同时跑好几个动画，画面撕裂。加了个"动画进行中锁"就解决了。

## 为什么归档了

**因为需求消失了。** 小朋友升到三年级，作业不再要求笔顺描红。项目本身没有通用性（强绑定我家孩子的教材版本），继续维护没有意义。

但这是我第一次真正把东西做到"有人用"，也是第一次体会到：**做小工具最大的敌人不是技术难度，而是需求会过期。**

所以现在我做东西的思路变了——先做最小可用版本，快速验证需求是否长期存在，再考虑投入更多。
